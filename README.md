# ERP Tamma — نظام إدارة معرض السيارات

نظام ويب إداري متكامل ومصمم خصيصاً لإدارة عمليات ومعارض السيارات، يركّز على دقة البيانات، تتبع الأرقام التعريفية المتعددة (الهيكل، المحرك، اللوحة، الجمارك)، تسجيل عمليات البيع والتسليم، وإصدار وثائق التسليم الرسمية القابلة للطباعة والتصدير كملفات PDF وفق المقاس القياسي A4.

> **العملة الرسمية المعتمدة في كافة أنحاء النظام:** الدينار الجزائري (**د.ج** / DZD).

---

## 1. التقنيات المعتمدة

- **Vite.js** لتطوير وبناء النظام بسرعة فائقة.
- **React 19 + TypeScript** لواجهة مستخدم حديثة وموثوقة بنمط Safe-Types.
- **React Router v7** لإدارة التوجيه والتنقل بين الصفحات وصفحات الطباعة المستقلة.
- **Tailwind CSS** مع Design Tokens مستوحاة من الهوية البصرية الإدارية الهادئة.
- **Supabase (PostgreSQL)** للمصادقة وتخزين البيانات وحماية الوصول عبر Row Level Security (RLS) ودوال المعاملات الآمنة.
- **Lucide React** للأيقونات الخطية الموحدة.
- خطوط Google المعتمدة: **IBM Plex Sans Arabic** للعربية، و**Inter** للأرقام والمعرفات اللاتينية.
- اتجاه الواجهة: **RTL** كامل على مستوى الجذر (`dir="rtl"`).

## 2. المميزات الرئيسية

1. **لوحة التحكم والمؤشرات:** إحصائيات فورية لعدد السيارات المتاحة، المبيعات المكتملة، إجمالي قيمة المخزون التقديرية بالدينار الجزائري، وجداول أحدث العمليات.
2. **إدارة المخزون والسيارات:**
   - تسجيل الماركة، الطراز، الفئة، سنة الصنع، اللون، نوع الوقود، ناقل الحركة، والعداد.
   - دعم **الأرقام التعريفية المتعددة** لنفس السيارة (رقم الهيكل VIN، رقم المحرك، اللوحة، الرقم الجمركي، أو رقم مخصص).
   - التحقق الفوري ومنع تكرار رقم الهيكل (VIN) على مستوى النظام.
   - بحث شامل فوري وسريع بواسطة الماركة أو الطراز أو أي من الأرقام التعريفية.
3. **المبيعات وعمليات الإخراج والتسليم:**
   - تسجيل عملية البيع للمشتري بسعر البيع والتخفيض بالدينار الجزائري (د.ج).
   - منع البيع المزدوج للسيارة وضمان قفل السجل وتغيير الحالة فورياً إلى «مباعة / مخرجة».
   - إمكانية إضافة عميل جديد مباشرة من نافذة البيع دون مغادرة الصفحة.
4. **وثائق PDF والطباعة الرسمية (A4):**
   - **بطاقة معلومات السيارة:** وثيقة رسمية A4 قابلة للطباعة والحفظ PDF تحتوي على كافة مواصفات السيارة وأرقامها التعريفية الموثقة وختم المعرض.
   - **وثيقة إخراج وتسليم سيارة:** وثيقة تسليم قانونية برقم مرجعي فريد وتاريخ العملية، بيانات المشتري، أرقام السيارة، البيانات المالية (د.ج)، وشروط التسليم، ومساحات توقيع المشتري ومسؤول المعرض.
5. **العملاء والموردون:** سجل كامل للمشترين والموردين مع أرقام الهاتف القابلة للنسخ والاتصال وسجل المركبات المرتبطة.
6. **التقارير وهوامش المبيعات:** احتساب الهامش الأولي التقديري (سعر البيع - سعر الشراء - المصاريف) وتصدير الجداول إلى CSV (Excel).
7. **إعدادات المعرض:** تخصيص اسم المعرض، الشعار، أرقام الهاتف، السجل التجاري، الرقم الجبائي، وشروط التسليم الرسمية.

## 4. خطوات التثبيت والتشغيل المحلي

### 1) تثبيت الحزم
```bash
npm install
```

### 2) إعداد متغيرات البيئة
قم بنسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
محتوى الملف:
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key-here
```
> **ملاحظة هامة:** في حال لم تقم بإدخال مفاتيح Supabase بعد، سيعمل النظام تلقائياً وبشكل كامل في **الوضع التجريبي المحلي (Persistent Local Mode)** مع بيانات أولية جاهزة، مما يتيح لك تجربة كامل خصائص النظام فوراً.

### 3) تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على الرابط: `http://localhost:5173`

### 4) بناء نسخة الإنتاج
```bash
npm run build
```

## 5. تهيئة قاعدة بيانات Supabase (PostgreSQL)

عند الربط بمشروع Supabase حقيقي:

1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. انتقل إلى تبويب **SQL Editor** في لوحة تحكم Supabase.
3. افتح ملف الهجرة المحفوظ في المشروع:
   `supabase/migrations/001_initial_schema.sql`
   وقم بنسخ محتواه ولصقه في محرر SQL ثم اضغط **Run**.
4. (اختياري) لتعبئة بيانات تجريبية أولية بالدينار الجزائري، قم بتشغيل محتوى:
   `supabase/seed.sql`
5. انسخ رابط المشروع `Project URL` والمفتاح العام `anon key` من إعدادات API وضعها في ملف `.env`.

## 6. هيكلية مجلدات المشروع

```text
src/
  app/
    router.tsx              # إعداد مسارات التطبيق وصفحات الطباعة
    providers.tsx           # المزودات العامة
  components/
    layout/
      AppLayout.tsx         # التخطيط العام
      Sidebar.tsx           # القائمة الجانبية باللغة العربية
      Header.tsx            # الشريط العلوي ومؤشر حالة الاتصال
    ui/                     # المكونات الأساسية (أزرار، حقول، وسوم، نوافذ)
  features/
    dashboard/              # لوحة التحكم والمؤشرات
    vehicles/               # إدارة المخزون، التفاصيل، وبطاقة السيارة A4
    sales/                  # المبيعات ووثيقة الإخراج والتسليم A4
    customers/              # إدارة العملاء وسجل التعاملات
    suppliers/              # إدارة الموردين
    reports/                # التقارير وهوامش الأرباح وتصدير CSV
    settings/               # إعدادات المعرض والشروط
  lib/
    supabase.ts             # عميل Supabase
    api.ts                  # واجهات التعامل مع البيانات (Supabase + Local Fallback)
    constants.ts            # ثوابت النظام، العملة (د.ج)، وألوان الحالات
    utils.ts                # أدوات التنسيق (formatCurrency, formatDate...)
  types/                    # تعريفات TypeScript
  index.css                 # تنسيقات Tailwind وخطوط الطباعة A4
supabase/
  migrations/
    001_initial_schema.sql  # مخطط الجداول والعلاقات والدوال وRLS
  seed.sql                  # بيانات تجريبية أولية
```
